{%- comment -%} ============================================================================ components/nav.html — Theme-managed, frontmatter-driven navigation tree ============================================================================ Mirrors the just-the-docs navigation model: page frontmatter drives the sidebar trees and sequential pagers. No per-site `_data` files are required. Every page contributes with: parent (string) exact title of the level-2 (parent) page grand_parent (string) exact title of the level-1 (grandparent) page nav_order (int) ascending sort position within its sibling group nav_icon (string) optional emoji/glyph for a level-1 category page published (bool) `false` hides the page from all navigation nav_exclude (bool) `true` hides this page from the nav tree only (the page is still built and reachable by URL) Category icons are resolved in this order: 1. `nav_icon:` in the category page's front matter 2. a `nav_icons:` map in `_config.yml`, keyed by title, path, or url: nav_icons: "Theme Documentation Directory": "📖" "wiki/index.md": "📚" 3. a keyword heuristic on the page title/path 4. a neutral folder fallback Visual hierarchy: Level 1 (category) pages render a category emoji. Level 2/3 (sub) pages render a left-aligned bullet. Include arguments: items (array) pages/documents to build the tree from active (string) page.path of the current page (active state) variant (string) "docs" (default sidebar) or "wiki" (wiki tree) ============================================================================ {%- endcomment -%} {%- assign nav_items = include.items -%} {%- if nav_items == nil or nav_items.size == 0 -%} {%- assign nav_items = site.html_pages -%} {%- endif -%} {%- assign nav_active = include.active -%} {%- assign nav_variant = include.variant | default: "docs" -%} {%- comment -%} Exclude unpublished and nav-excluded pages from every tree {%- endcomment -%} {%- assign nav_items = nav_items | where_exp: "item", "item.published != false" -%} {%- assign nav_items = nav_items | where_exp: "item", "item.nav_exclude != true" -%} {%- comment -%} Level 1: pages without a `parent` {%- endcomment -%} {%- assign nav_l1 = "" | split: "" -%} {%- for item in nav_items -%} {%- assign item_parent = item.parent | default: "" -%} {%- if item_parent == "" -%} {%- assign nav_l1 = nav_l1 | push: item -%} {%- endif -%} {%- endfor -%} {%- assign nav_l1 = nav_l1 | sort: "nav_order" -%} {%- if nav_variant == "wiki" -%}
