## 🎨 Catalogue Layout

This page demonstrates the `catalogue` layout structure. No themes or items have been published to this catalogue yet.

### How to Add Items

In your site repository, declare items in your page frontmatter or in `_data/catalogue.yml`:

```yaml
categories:
  - Category A
  - Category B

items:
  - title: Item Name
    category: Category A
    badge: Optional Badge
    version: v1.0.0
    description: Item description here...
    tags: [Tag1, Tag2]
    preview_url: https://...
    docs_url: /docs/...
    github_url: https://github.com/...
```
