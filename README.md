Cohesive obsidian design system, modular include partials, frontmatter-driven tree navigation, 18-language Google Translate switcher, and native Mermaid diagram support.

## ⚡ Quick Start

### GitHub Pages (Remote Theme)
Add to your site's `_config.yml`:

```yaml
remote_theme: HELIX-Origin/helix-jekyll-theme
plugins:
  - jekyll-remote-theme
```
